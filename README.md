# Ezharp

An HTML5 version of the Easy Harp music instrument. Simply type or tap chords to create music on the fly.

## Features
* **Advanced Chord Modes:** Full support for various chord types including major, sus2, sus4, diminished, and augmented.
* **Note Sustain & Damping:** Realistic string behavior with proper envelope controls.
* **Instrument Emulation:** Includes distinct sound profiles like ukulele and piano.
* **Multitouch Grid:** A responsive interface built for complex chord progressions.
